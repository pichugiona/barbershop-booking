# 💈 Система онлайн-записи в барбершоп

## 📌 О проекте

Учебный pet-проект по анализу, моделированию и проектированию системы онлайн-записи клиентов в барбершоп.

Проект представляет собой комплексную работу, включающую анализ бизнес-процессов, моделирование архитектуры системы, проектирование структуры данных и разработку концепции автоматизированной системы записи. Основная цель — создать полноценную систему, которая автоматизирует процесс записи клиентов, управление расписанием мастеров, информирование клиентов и сбор обратной связи.

В рамках проекта проведен глубокий анализ предметной области, выделены основные сущности и бизнес-правила, разработаны модели процессов и структура данных, позволяющая эффективно управлять всеми аспектами работы барбершопа.

> **Тип проекта:** учебный pet-project  
> **Роль:** Junior Business / System Analyst  
> **Направление:** Business Analysis / System Analysis  
> **Инструменты:** BPMN, IDEF0, UML, Draw.io, ER-моделирование  
> **Статус:** In progress

---

## 🎯 Цель проекта

Разработать концепцию и архитектуру системы онлайн-записи, которая позволит:

- клиентам записываться на услуги онлайн в любое время суток;
- выбирать тип услуги (парикмахерские или косметологические);
- выбирать конкретную услугу из каталога с описанием и ценой;
- выбирать мастера с учетом его специализации и рейтинга;
- выбирать свободное время из актуального расписания;
- получать автоматические напоминания о записи;
- оставлять оценку и отзыв после посещения;
- менеджеру управлять расписанием и перечнем услуг;
- мастерам просматривать свое расписание и отзывы.

## 🏢 Бизнес-контекст

### О компании

Сеть барбершопов предоставляет парикмахерские и косметологические услуги. Для повышения качества обслуживания и расширения клиентской базы принято решение о внедрении системы онлайн-записи.

### Проблемы текущего процесса

- Ручная запись клиентов по телефону создает нагрузку на администраторов
- Частые пропуски записей из-за отсутствия напоминаний
- Сложность координации расписания между мастерами
- Отсутствие системы сбора обратной связи
- Невозможность анализировать загрузку мастеров и популярность услуг

### Ожидаемые результаты внедрения

- Снижение трудозатрат персонала на 30-40%
- Увеличение количества записей за счет доступности 24/7
- Снижение числа пропущенных записей на 50% через автоматические напоминания
- Повышение качества обслуживания через обратную связь
- Возможность аналитики и планирования ресурсов

## 📋 Системные требования

### Функциональные требования

**Клиентская часть:**
| Требование | Описание |
|------------|----------|
| Регистрация | Возможность регистрации с указанием контактов и предпочтений по каналам связи |
| Каталог услуг | Просмотр услуг с ценами, описанием и длительностью |
| Выбор мастера | Просмотр мастеров с указанием специализации и рейтинга |
| Выбор времени | Отображение свободных интервалов с учетом загрузки мастера |
| Создание записи | Бронирование выбранной услуги на конкретное время |
| Уведомления | Получение напоминаний через Telegram, WhatsApp, VK, СМС |
| Отзывы | Оценка услуги и оставление комментария после посещения |

**Административная часть (менеджер):**
| Требование | Описание |
|------------|----------|
| Управление мастерами | Добавление, редактирование и удаление мастеров |
| Управление услугами | Создание и редактирование услуг, привязка к мастерам |
| Расписание | Ввод и корректировка рабочих часов мастеров |
| Управление записями | Просмотр, подтверждение и отмена записей |
| Отметка выполнения | Подтверждение оказания услуги |
| Оплата | Прием и учет оплаты, передача данных в бухгалтерию |
| Отчетность | Формирование отчетов по записям, выручке, загрузке мастеров |
| Просмотр отзывов | Чтение и анализ обратной связи клиентов |

**Мастерская часть:**
| Требование | Описание |
|------------|----------|
| Расписание | Просмотр своих рабочих часов и записей |
| Отзывы | Просмотр отзывов о своей работе |
| Статистика | Просмотр количества выполненных услуг |

### Нефункциональные требования

- Доступность системы 24/7
- Быстрый поиск свободного времени (ответ < 1 секунды)
- Автоматическая отправка уведомлений по расписанию
- Безопасность персональных данных клиентов
- Масштабируемость для нескольких филиалов

## 👥 Участники системы

| Роль | Описание | Основные действия |
|------|----------|-------------------|
| 👤 Клиент | Физическое лицо, желающее получить услугу | Регистрация, выбор услуги, мастера и времени, запись, получение уведомлений, оценка услуги |
| 💇 Мастер | Сотрудник, оказывающий услуги | Оказание услуги, просмотр расписания, просмотр отзывов |
| 👨‍💼 Менеджер | Сотрудник, управляющий системой | Управление расписанием и услугами, отметка выполнения, прием оплаты, формирование отчетов |
| 🤖 Система | Автоматизированный компонент | Обработка записи, проверка доступности времени, отправка уведомлений, сбор обратной связи |
| 📊 Бухгалтерия | Внешняя система | Получение данных об оплатах |
