# 💈 Система онлайн-записи в барбершоп | Учебный pet-проект, 2026 — Завершен

## 📌 О проекте
Учебный pet-проект по системному и бизнес-анализу, моделированию и проектированию системы онлайн-записи клиентов в барбершоп.

Проект представляет собой комплексную работу, включающую анализ бизнес-процессов, моделирование архитектуры системы, проектирование структуры данных, разработку концепции автоматизированной системы записи и интеграционных интерфейсов. 

Основная цель — создать полноценную систему, которая автоматизирует процесс записи клиентов, управление расписанием мастеров, информирование клиентов и сбор обратной связи. В рамках проекта проведен глубокий анализ предметной области, выделены основные сущности и бизнес-правила, разработаны модели процессов и структура данных, позволяющая эффективно управлять всеми аспектами работы барбершопа.

* **Тип проекта:** Учебный pet-project
* **Роль:** Junior Business / System Analyst
* **Направление:** Business Analysis / System Analysis
* **Статус:** Completed

## 🎯 Цель проекта
Разработать концепцию и архитектуру системы онлайн-записи, которая позволит:
* клиентам записываться на услуги онлайн в любое время суток;
* выбирать тип услуги, конкретную услугу из каталога и мастера с учетом специализации;
* выбирать свободное время из актуального расписания;
* получать автоматические напоминания о записи;
* оставлять оценку и отзыв после посещения;
* менеджеру управлять расписанием, услугами и оплатой;
* мастерам просматривать свое расписание и отзывы.

## 🏢 Бизнес-контекст
**Проблемы текущего процесса:**
* Ручная запись клиентов по телефону создает нагрузку на администраторов.
* Частые пропуски записей из-за отсутствия напоминаний.
* Сложность координации расписания между мастерами.
* Отсутствие системы сбора обратной связи и аналитики.

**Ожидаемые результаты внедрения:**
* Снижение трудозатрат персонала на 30-40%.
* Увеличение количества записей за счет доступности 24/7.
* Снижение числа пропущенных записей на 50% через автоматические напоминания.
* Повышение качества обслуживания через обратную связь.
